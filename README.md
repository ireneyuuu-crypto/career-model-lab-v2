# Career Model Lab V1.8

保留 V1.7 的相位计算、职业候选主题、星空封面、手绘插画和塔罗互动。新增**实验性职业发展综合指数（0–100）**、十年可点击曲线及结论先行的总览。

指数不等于实际升职或涨薪概率，尚未校准。组织支持/稳定性缺少现实信息，没有用假数据代替。**50分表示未检出相关主信号，不是现实中的平均职业水平。**

上传本压缩包中全部文件到 GitHub 仓库根目录；`ephemeris.json` 必须和 `index.html` 同级。静态网页，无须服务器。

## 本地测试
`npm test`；`python3 -m http.server 8080`，打开 http://localhost:8080

## 变更
- 新增 `career-index.js`、趋势图和重点信息首页
- 将原相位数量图放进折叠专业区域
- PDF/JSON 包含实验性指数

- 保留塔罗功能，但独立塔罗图像不属于此版本

## 公开示例隐私规则
- 演示按钮使用完全虚构的样本日期/时间/地点；与项目开发者或真实使用者无关。
- 示例报告只使用人工构造的主题、趋势和年份，不能从任何个人星盘生成示范预测。
- 公开仓库不上传真实用户星盘、报告、导出文件或任何可识别信息。
- `ephemeris.json` 包含通用天文历表，涵盖大量年份；单独出现某一年的历表不代表用户的出生年份。
